InfraXcode ↗

GENAI Developer → NetDevOps Engineer

Sep 2023 – Mar 2025 · Paris, FR (Remote)

Built an LLM-backed network device emulator as part of an R&D platform that allowed NetDevOps and development teams to launch stateful emulated devices instead of provisioning physical sandboxes, enabling them to connect management planes and run Infrastructure-as-Code and configuration management workflows directly on top of the emulator. The agent roleplayed as a real network device by maintaining session state and grounding responses using vendor CLI documentation and YANG specifications through a RAG + BM25 pipeline. I implemented both the SSH server and RESTCONF server from scratch, allowing existing Ansible playbooks and Terraform providers to connect without modification, and the NetOps team successfully executed real automation scripts against it with roughly 80% output parity compared to physical hardware. Major engineering challenges included persistent session state management across runs (evaluating local file storage versus Neo4j), handling context window overflow through a summarization node that compressed conversation history while preserving operational state, improving response accuracy through retrieval tuning and prompt engineering, and addressing latency tradeoffs inherent to token generation. On the same platform, I also developed a test-case orchestration system where engineers could define automation scripts alongside multiple simulated device states such as closed SSH ports, invalid credentials, or missing configurations; the orchestrator dynamically spawned emulated devices for each scenario, executed the scripts, and returned side-by-side results to expose failure cases before deployment to production hardware. Midway through the project, I migrated the platform away from external LLM providers such as OpenAI and Groq by deploying locally hosted fine-tuned Llama models through Hugging Face and Ollama, removing third-party API dependencies and improving inference latency.
